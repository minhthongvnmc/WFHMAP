# WFHMC City (Bedrock Edition)

**WFHMC City** (formerly *World Flat House Map*) is a large-scale, intricate urban construction project built within Minecraft Bedrock Edition by **MinhthongVNMC Studio**. Initially launched in its alpha phase on May 29, 2023, the map represents an ongoing effort to transform a standard flat landscape into a lively, modern metropolis.

---

### 📌 Project Information

- **Developer:** MinhthongVNMC Studio
- **Platform:** Minecraft Bedrock Edition
- **Creation Date:** May 29, 2023
- **Current Status:** Beta Version *(Official full release targeted for December 2027)*
