# WFHMC City (Bedrock Edition)

WFHMC City (formerly known as World Flat House Map) is a vast, highly detailed urban development project in Minecraft Bedrock Edition, engineered by MinhthongVNMC Studio. First launched as an early alpha build on May 29, 2023, it stands as the culmination of continuous creative passion, transforming a standard flat world into a vibrant, immersive modern metropolis.

---

### 📌 Project Information
- **Project Name:** WFHMC City (Bedrock Edition)
- **Developer / Studio:** MinhthongVNMC Studio
- **Platform:** Minecraft Bedrock Edition
- **Initial Creation Date:** May 29, 2023
- **Status Note:** Currently in Beta development. The full official release is scheduled for December 2027.
