# WFHMC City (Bedrock Edition)

WFHMC City (formerly World Flat House Map) is a large-scale, highly detailed urban development project for Minecraft Bedrock Edition, crafted by MinhthongVNMC Studio. First released as an alpha version on May 29, 2023, it represents a continuous creative journey to transform a flat world into a thriving, modern metropolis.

---

### 📌 Project Information

- **Creator:** MinhthongVNMC Studio
- **Platform:** Minecraft Bedrock Edition
- **Initial Creation Date:** May 29, 2023
- **Status:** Beta Release *(Official release scheduled for December 2027)*
