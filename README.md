# WFHMC City (Bedrock Edition)

WFHMC City (formerly *World Flat House Map*) is a large-scale, highly detailed urban development project built for Minecraft Bedrock Edition by MinhthongVNMC Studio. Originally released as an Alpha version on May 29, 2023, the project represents a continuous creative journey dedicated to transforming a flat world into a thriving, modern metropolis.

---

### 📌 Project Information

- **Creator:** MinhthongVNMC Studio
- **Platform:** Minecraft Bedrock Edition
- **Initial Creation Date:** May 29, 2023
- **Note:** This project is currently in Beta. The full official release is planned for December 2027.
