# WFHMC City (Bedrock Edition)

**WFHMC City** (formerly known as *World Flat House Map*) is an expansive, intricately detailed urban development project built for Minecraft Bedrock Edition, crafted by **MinhthongVNMC Studio**. Initially launched in its alpha phase on May 29, 2023, the map represents an ongoing journey of continuous creative effort—transforming a blank, flat world into a thriving, modern metropolis.

---

### 📌 Project Information

- **Creator / Developer:** MinhthongVNMC Studio
- **Platform:** Minecraft Bedrock Edition
- **Initial Creation Date:** May 29, 2023
- **Current Status:** Beta Version (Official Full Release expected in December 2027)
