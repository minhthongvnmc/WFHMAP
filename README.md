# WFHMC City (Bedrock Edition)

WFHMC City (formerly World Flat House Map) is a large-scale, meticulously designed urban project built for Minecraft Bedrock Edition, crafted by MinhthongVNMC Studio. Initially launched in Alpha on May 29, 2023, it stands as the product of ongoing creative dedication to transforming a flat world into a thriving, modern metropolis.

---

### 📌 Project Information

- **Creator / Studio:** MinhthongVNMC Studio
- **Platform:** Minecraft Bedrock Edition
- **Initial Release Date:** May 29, 2023
- **Status:** Beta Release (Official Version Scheduled for December 2027)
