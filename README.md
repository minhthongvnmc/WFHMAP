# WFHMC City (Bedrock Edition)

WFHMC City (formerly World Flat House Map) is a large-scale, highly detailed urban development project in Minecraft Bedrock Edition, created and developed by MinhthongVNMC Studio. First launched in its alpha phase on May 29, 2023, the project represents a continuous creative journey to transform a flat world into a vibrant, modern metropolis.

---

### 📌 Project Information

- **Project Name:** WFHMC City (Bedrock Edition)
- **Developer / Creator:** MinhthongVNMC Studio
- **Platform:** Minecraft Bedrock Edition
- **Initial Release:** May 29, 2023
- **Status:** Beta Release (Official full release scheduled for December 2027)
