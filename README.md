# WFHMC City (Bedrock Edition)

**WFHMC City** (formerly known as *World Flat House Map*) is a large-scale, highly detailed urban development project for Minecraft Bedrock Edition, crafted by **MinhthongVNMC Studio**. Originally debuted in its alpha stage on May 29, 2023, the map is the culmination of continuous creative passion, transforming a flat world canvas into a thriving modern metropolis.

---

### 📌 Project Information

- **Creator:** MinhthongVNMC Studio
- **Platform:** Minecraft Bedrock Edition
- **Initial Creation Date:** May 29, 2023
- **Notice:** This project is currently in **Beta** and does not represent the final release. Stay tuned for the official launch in **December 2027**!
