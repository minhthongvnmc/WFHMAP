# WFHMC City (Bedrock Edition)

WFHMC City (formerly World Flat House Map) is a large-scale, highly detailed urban development project in Minecraft Bedrock Edition created by MinhthongVNMC Studio. First launched as an alpha build on May 29, 2023, the project represents an ongoing creative endeavour to transform a flat terrain map into a thriving modern metropolis.

---

### 📌 Project Information

- **Creator:** MinhthongVNMC Studio
- **Platform:** Minecraft Bedrock Edition
- **Initial Release Date:** May 29, 2023
- **Current Status:** Beta Version *(Official full release scheduled for December 2027)*
